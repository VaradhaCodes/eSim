● Confirmed both root causes.

  Bug 1 (VerilogVerifier.py): _sync_hierarchy_widths sets
  rw.setFixedWidth(viewport().width()), but QSS #verilogHierarchyList::item { 
  padding:7px 10px; margin:1px } insets the item widget — so a row forced to
  full viewport width overflows right → down-arrow clipped, scales with window.

  closeEvent to the nested Maker, so its watchdog observer + toggle QThread 
  survive. Second "Send to Makerchip" overwrites the same .v file → stale
  observer fires on_modified → emits into the deleted refresh button → segfault,
  esim dies.
